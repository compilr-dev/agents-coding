# Contributing to @compilr-dev/agents-coding

Thanks for your interest in contributing to the compilr.dev coding tools ecosystem.

## Reporting Issues

Found a bug or have a feature idea? [Open an issue](https://github.com/compilr-dev/agents-coding/issues/new/choose) using one of our templates:

- **Bug Report** -- Include your package version, which sub-package is affected, and a minimal reproduction.
- **Feature Request** -- Describe the use case and which language/tool area is involved.

Good bug reports include:
- Which package is affected (`agents-coding`, `agents-coding-core`, `agents-coding-ts`, `agents-coding-python`, or `agents-coding-go`)
- A minimal code snippet or project structure that reproduces the problem
- The target language of the code being analyzed (TypeScript, Python, Go)
- Your environment (OS, Node.js version)

## Source Code

This repository is a **public mirror** for issue tracking and documentation. The source code is developed in a private repository. We publish compiled packages to npm.

**Pull requests are not currently accepted.** If you have a code contribution in mind, please open an issue first to discuss the approach.
